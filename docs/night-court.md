# 永夜王庭画面对照

Pages #15 对应 `c25ca24`。#16 为 `8fb02e7`，回退后的 #17 为 `c4fc9b2`。本次工作从 #17 建立工作分支，核对时 #15 和 #17 的文件树一致。

## 取景与操作

#15 的模式选择在 1440 × 900 与 390 × 844 都隐藏了整个预览容器。新版把预览放入正常布局，桌面与选择区并排，竖屏放在两个对战入口下方。两种规则共用同一套石台材质、灯位和棋具。大厅、祭台及五位对手共八张 WebP，由仓库自己的模型在 Three.js 中离线取景；继续对局使用实时 WebGL。大厅图 88,974 字节，加载期间先显示随程序内联的 3,488 字节静帧。

普通落子在落定事件生成五片贴地尘屑并播放石面音。普通吃子在命中帧产生定向火花与受力反馈，之后公开身份。斩杀按规则引擎给出的每一步分别点亮窄剑痕。祭典在公开事件到达时依次点亮三个符印，减少动态效果时同时显示完整符印。占领方的王阵亡后，熄灭该方占领光效并显示打断通知。视角工具位于游戏顶栏。

## 核验

- Chromium 156，Debian Linux，SwiftShader 软件图形后端。桌面 1440 × 900、1280 × 720；模拟触屏 390 × 844 和 844 × 390。手机真机、Safari、硬件 GPU 帧率未实测。
- 在正式包中拦住大厅高清图的请求，验证内联静帧已经显示，点击「开启棋局」可立即进入选择。首次进大厅时分配的 WebGL 画布数为 0。
- 145 项单元测试通过。新增的特效测试覆盖点灯顺序、减少动态效果、经典模式隔离、落点粒子释放以及占领方王被吃后的熄灯。
- 浏览器实测四种尺寸的规则切换、两种规则下的预览、五名对手、全知者告知、布阵入口、棋盘投影边界及工具条位置。桌面鼠标与手机触控均实测吃子、跳过与离开进行中的动作。
- 浏览器页面冻结 2.3 秒后恢复，双目标斩杀只结算两次命中，未重播过期命中音。正式包实测落子、认输、再来一局和重新布阵。
- 对照截图在正式构建上沿菜单实际进入。录屏使用测试构建设置相同局面，执行真实棋盘输入、渲染和声音。逐帧 MP4 以动作时钟采样；WebM 保留浏览器的实际输出节奏。相机、视口、缩放和画质相同。
